# TaskFlow

A day-by-day task board with built-in time tracking. Single HTML file, no install.

- Board / List / Report views with To-Do, In Progress, In Review, Done, Blocked
- Start/stop timers per task, manual time entries, daily and weekly totals
- Descriptions, subtasks, timestamped remarks and change history
- Carry unfinished tasks over to a new day

Data is stored in your browser's local storage — use **Export** to back it up and **Import** to restore or move it to another device.

Open `index.html` directly, or use the hosted version on GitHub Pages.
